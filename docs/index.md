# Type Omega Dev Docs

Developer documentation for **Type Omega** (formerly GregTech Infinity Ascension), a GregTech modpack for Minecraft 1.20.1 built on GTCEu Modern, the GregTech Nexus Addon (GTNA) and TypeOmega Core.

This site is for people who build the pack: what it is trying to be, how decisions are made, and how to write code for it. Players should start at the [modpack repository](https://github.com/Type-Omega/TypeOmega).

Community: [Discord](https://discord.gg/TW5vugknk5) · questions, bug reports and playtesting.

| Section | What you find there |

| [Governance](governance/decisions.md) | Approved decisions and how releases work |

## Repositories

| Repository | Role |
| --- | --- |
| [TypeOmega](https://github.com/Type-Omega/TypeOmega) | The modpack: configs, KubeJS, quests, manifest |
| [TypeOmegaCore](https://github.com/Type-Omega/TypeOmegaCore) | Core mod: pack machines, chemistry slices, megastructures |
| [GregTech-Nexus-Addon](https://github.com/Type-Omega/GregTech-Nexus-Addon) | GTNA: large machines, Nexus energy network, endgame multiblocks |
| [Agronomica](https://github.com/Type-Omega/Agronomica) | Crop breeding mod (early development) |

Policies that apply everywhere live in the organisation's [.github repository](https://github.com/Type-Omega/.github): Code of Conduct, AI policy and contribution guidelines.
